# Campaign Visual Projects

Use this entry as a source-linked case library for campaign visual systems, not
as a bundle of copied promotional artwork.

Each entry should preserve the smallest durable signal:

- `project`: title, maker, URL, medium, and format.
- `why`: why the campaign system is worth keeping.
- `artDirection`: image strategy, type behavior, color logic, and campaign framing.
- `channelFormats`: how the system flexes across posters, signage, social, OOH, merch, and spatial touchpoints.
- `assets`: reusable graphic ingredients, photography logic, illustration systems, and pattern language.
- `motion`: cutdowns, motion-led expressions, and fallback behavior.
- `interactions`: only when a digital extension adds meaningful behavior.
- `implementation`: format, complexity, and evidence limits.
- `capture`: date, source links, attribution, reuse policy, and capture depth.

Use `status: lead` when the source is promising but still needs a stronger read
of the campaign rollout. Use `status: accepted` when the page gives enough
evidence to preserve the reusable campaign grammar.
