# Animated SVG Logo Draw

Use this template when a site needs a tiny but memorable identity gesture: a logo or monogram that draws itself, resolves cleanly, and still reads well when motion is disabled.

Keep the output original. Reuse the motion principle, not another brand's exact mark, control points, copy, or geometry.
