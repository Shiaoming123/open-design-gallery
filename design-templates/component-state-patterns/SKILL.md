# Component State Patterns

Keep this as a sharded, source-linked case library. `references/catalog.json`
contains only an `entryFiles` index; every accepted reference lives in its own
file under `references/entries/` and must validate against
`references/entry.schema.json`.

Capture the state transition, user recovery path, keyboard and screen-reader
behavior, implementation evidence, source links, attribution, reuse policy,
and capture depth. Do not save external screenshots or commercial assets.
