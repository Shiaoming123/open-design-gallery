# Markdown Minimal Resume

Design a quiet, content-first Chinese resume that feels like well-rendered Markdown rather than a decorated poster. Use one column, strong typographic hierarchy, sparse dividers, compact bullets, and no ornamental imagery. Prioritize ATS-safe text, consistent dates, measurable achievements, and enough whitespace for print readability.
