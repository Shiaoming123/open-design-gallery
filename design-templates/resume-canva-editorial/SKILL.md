# Resume Canva Editorial

Use this template when a candidate needs a creative resume that still reads like a serious document. Build a strong name block, subtle editorial rhythm, and a few restrained visual accents. Keep all imagery abstract or CSS-based, preserve print contrast, and avoid copying any Canva template, thumbnail, logo, or proprietary composition.
