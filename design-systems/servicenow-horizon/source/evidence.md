# ServiceNow Horizon Source Evidence

## Source Scope

This Open Design capture distills public, official ServiceNow Horizon documentation into reusable visual language. It does not copy official screenshots, image assets, Figma libraries, code, or proprietary component source.

## Reviewed Sources

- https://horizon.servicenow.com/ — home page positioning: Horizon as the source of truth for ServiceNow experience design, with emphasis on enterprise experiences, AI guidance, app frameworks, and resources.
- https://horizon.servicenow.com/getting-started/all — getting-started overview and information architecture for guidelines, AI, principles, design, development, and UX basics.
- https://horizon.servicenow.com/getting-started/design — design workflow guidance, Figma libraries, styles, components, templates, and theme builder references.
- https://horizon.servicenow.com/getting-started/principles — named principles: Fluid, Symphonic, Resonant.
- https://horizon.servicenow.com/guidelines/all — guideline categories including accessibility, conversation design, words, and unified navigation.
- https://horizon.servicenow.com/getting-started/develop — Next Experience UI Framework and developer resources.

## Distillation Notes

- The visual system is interpreted as calm enterprise workflow design: light canvas, white surfaces, green action color, structured cards, and clear status language.
- The component fixture uses synthetic copy and layout patterns only.
- Color and typography values are normalized Open Design tokens chosen to express the observed design intent rather than extracted proprietary implementation tokens.
