## Distilled Observations

- Spectrum treats tokens as design decisions and a source of truth across color, typography, spacing, animation, and component styling.
- The visual language is neutral, application-oriented, and token-led rather than decorative.
- The color system uses grays for most UI structure and reserves blue for action, selection, links, and focus.
- Typography centers on Adobe Clean, with Source Code Pro for code-like contexts.
- Spacing documentation exposes small incremental spacing tokens, supporting dense product surfaces and precise component layout.
- Spectrum CSS emphasizes token-backed CSS custom properties and theming, so this Open Design package keeps every visible value routed through the standard token schema.

## Capture Notes

This package is an original Open Design distillation. Color values and component shapes are intentionally approximate reusable guidance for generated artifacts, not a vendored copy of Spectrum source files.
