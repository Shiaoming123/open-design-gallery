# Backstage Design System Source Evidence

## Source Scope

This Open Design capture distills public Backstage and Spotify for Backstage materials into reusable visual language. It does not copy official screenshots, logos, image assets, or source implementation.

## Reviewed Sources

- https://backstage.spotify.com/ — public Spotify for Backstage site, including developer portal positioning, dark visual language, product/plugin framing, and visible references to Software Catalog, Software Templates, AiKA, Data Experience, Confidence, Soundcheck, RBAC, Skill Exchange, and Insights.
- https://backstage.io/docs/overview/what-is-backstage/ — official overview describing Backstage as an open-source framework for internal developer portals powered by a centralized software catalog.
- https://backstage.io/docs/dls/design/ — Backstage design system guidance describing the relationship between Backstage Design System, Material UI, core UX, Storybook, Figma resources, and theme customization.
- https://backstage.io/docs/dls/component-design-guidelines/ — component guidance around layout, color palette, typography, Material UI containers/grids/paper/cards, and theme-aware component construction.
- https://backstage.io/docs/conf/user-interface/ — theme customization documentation for `createUnifiedTheme`, palettes, typography, spacing, shape, page themes, and component overrides.
- https://backstage.io/api/next/modules/_backstage_theme.html — API documentation for `@backstage/theme`, including theme variables and unified theme functions.
- https://github.com/backstage/backstage — open-source repository reference for project identity, package structure, and theme/provider model.
